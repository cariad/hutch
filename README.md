# hutch

Website hosting in bunny.net.

> [!NOTE]
> hutch is an independent, unofficial project. It isn't affiliated with, endorsed, or supported by bunny.net. It's just a tool written by a fan to deploy infrastructure.

## Installation

hutch needs Python 3.14 or later, and is published to [PyPI](https://pypi.org/p/hutch).

Install it as a standalone tool with [pipx](https://pipx.pypa.io/):

```bash
pipx install hutch
```

Or try it without installing anything:

```bash
pipx run hutch
```

## Usage

Print help:

```bash
hutch --help
```

Print the version:

```bash
hutch --version
```
